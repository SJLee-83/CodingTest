[문제 설명]

N x N 크기의 격자 모양인 공간에서 자동화 농장을 운영하려고 한다.

이 문제에서는 농장 내의 위치를 (행, 열)로 나타내며, 각 위치에 작물을 심을 수 있다.

 

농장에서는 3가지 품종의 작물을 재배하고 있으며, 각 작물은 품종에 따른 성장 시간을 가진다.

모든 작물은 작물이 심어진 시간으로부터 해당 작물 품종의 성장 시간만큼의 시간이 흐르면 크기가 1만큼 성장한다.

 

농장에서는 작물의 성장을 돕기 위해 화학 첨가물이 가미된 물을 급수할 수 있으며, 물을 맞은 작물들은 지정된 값만큼 크기가 성장한다.

 

효율적인 운영을 위해, 농장은 자동 수확 시스템을 채택하였다.

자동 수확 시스템은 농장 내 특정 지역을 스캔하여, 대상 지역 내의 모든 작물의 크기가 기준 값을 넘을 경우, 해당 지역의 작물을 전체 수확한다.

 

아래 API 설명을 참조하여 각 함수를 구현하라.

※ 아래 함수 signature는 C/C++에 대한 것으로 다른 언어에 대해서는 제공되는 Main과 User Code를 참고하라.

void init(int N, int mGrowthTime[])

각 테스트 케이스의 처음에 호출된다.

농장의 크기 N과 각 작물 품종에 따른 성장 시간이 mGrowthTime 배열로 주어진다.

초기 농장에 심어진 작물은 없다.

 

__Parameters

_____N : 농장의 한 변의 길이 (10 ≤ N ≤ 1,000)

_____mGrowthTime[i] : i 품종 작물의 성장 시간 (0 ≤ i ＜ 3, 1 ≤ mGrowthTime[i] ≤ 30)

int sow(int mTime, int mRow, int mCol, int mCategory)

mTime 시점에 농장 내 (mRow, mCol) 위치에 mCategory 품종 작물을 심는다.

기존 (mRow, mCol) 위치에 작물이 심어져 있는 경우, 작물을 심을 수 없으며 0을 반환한다.

정상적으로 작물이 심어진 경우 1을 반환한다.

심어진 작물의 초기 크기는 0이다.

 

__Parameters

_____mTime : 현재 시간 (1 ≤ mTime ≤ 1,000,000)

_____mRow : 작물이 심어질 행 위치 (0 ≤ mRow < N)

_____mCol : 작물이 심어질 열 위치 (0 ≤ mCol < N)

_____mCategory : 작물의 품종 (0 ≤ mCategory ＜ 3)

 

__Returns

_____작물을 심은 경우 1, 심지 못한 경우 0

int water(int mTime, int G, int mRow, int mCol, int mHeight, int mWidth)

mTime 시점에 (mRow, mCol) 위치를 좌측 상단 꼭지점으로 mHeight 세로 길이와 mWidth 가로 길이를 가지는 직사각형 구역에 물을 급수한다.

물이 급수되는 구역에 존재하는 모든 작물은 크기가 G 만큼 성장하며, 해당 구역에 존재하는 작물의 수를 반환한다.

급수로 인해 작물의 크기가 변해도, 기존 성장 시간에 따른 크기 변화에는 영향을 주지 않는다.

ex) 성장 시간이 4인 작물을 심은 후 3의 시간이 흘렀을 때 물을 주어도, 추가로 1의 시간이 흐르면 작물의 크기는 1 성장한다.

물이 급수되는 구역의 크기는 농장을 벗어나지 않는 범위 내에서 주어진다.

 

__Parameters

_____mTime : 현재 시간 (1 ≤ mTime ≤ 1,000,000)

_____G : 급수할 지역에서 작물이 성장할 크기 (1 ≤ G ≤ 10)

_____mRow : 급수할 지역의 좌측 상단 꼭지점의 행 위치 (0 ≤ mRow < N)

_____mCol : 급수할 지역의 좌측 상단 꼭지점의 열 위치 (0 ≤ mCol < N)

_____mHeight : 급수할 지역의 세로 길이 (1 ≤ mHeight ≤ N)

_____mWidth : 급수할 지역의 가로 길이 (1 ≤ mWidth ≤ N)

 

__Returns

_____급수할 지역에 존재하는 작물의 수

int harvest(int mTime, int L, int mRow, int mCol, int mHeight, int mWidth)

mTime 시점에 (mRow, mCol) 위치를 좌측 상단 꼭지점으로 mHeight 세로 길이와 mWidth 가로 길이를 가지는 직사각형 구역에서 수확을 진행한다.

수확을 진행할 구역에 존재하는 작물의 크기가 모두 L 이상인 경우 수확을 진행하며, 수확된 작물의 수를 반환한다.

만약 크기가 L 미만인 작물이 하나라도 존재한다면, 구역 내 작물에는 변화가 발생하지 않은 채 수확에 실패하고 0을 반환한다.

수확이 진행된 구역에는 더 이상 작물이 존재하지 않는다.

작물을 수확하는 구역의 크기는 농장을 벗어나지 않는 범위 내에서 주어진다.

 

__Parameters

_____mTime : 현재 시간 (1 ≤ mTime ≤ 1,000,000)

_____L : 수확에 필요한 최소 작물 크기 (0 ≤ L ≤ 100)

_____mRow : 수확할 지역의 좌측 상단 꼭지점의 행 위치 (0 ≤ mRow < N)

_____mCol : 수확할 지역의 좌측 상단 꼭지점의 열 위치 (0 ≤ mCol < N)

_____mHeight : 수확할 지역의 세로 길이 (1 ≤ mHeight ≤ N)

_____mWidth : 수확할 지역의 가로 길이 (1 ≤ mWidth ≤ N)

 

__Returns

_____수확한 작물의 수

[제약사항]

1. mTime 값은 항상 증가하는 값으로 주어진다.

2. 각 테스트 케이스 시작 시 init() 함수가 한 번 호출된다.

3. 각 테스트 케이스에서 sow() 함수의 호출 횟수는 최대 100,000이다.

4. 각 테스트 케이스에서 water() 함수의 호출 횟수는 최대 10,000이다.

5. 각 테스트 케이스에서 harvest() 함수의 호출 횟수는 최대 10,000이다.

 

[입출력]

입출력은 제공되는 Main 부분의 코드에서 처리하므로 User Code 부분의 코드에서는 별도로 입출력을 처리하지 않는다.

Sample input 에 대한 정답 출력 결과는 “#TC번호 결과” 의 포맷으로 보여지며 결과가 100 일 경우 정답, 0 일 경우 오답을 의미한다.
