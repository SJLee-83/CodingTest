# Big-O 법칙
- 상수배는 무시
- ex) O(N) + O(N) + O(N) = O(N)

# 초당 연산수
- C++ 기준 1초 1억번
- N이 10~20 정도면 O(2ᴺ)이나 O(N!)
- N이 100~500이면 O(N³)
- N이 1,000~5,000이면 O(N²)
- N이 10만~100만이면 O(N log N)이나 O(N)
- N이 1,000만 이상이면 O(N)조차 빠듯해서 O(log N)이나 O(1)

# 이중 반복문
- O(N^2)
- ex) N = 100000 -> 최대 연산 수 = 100억

# 해시 - unordered_map
- O(N)
- 접근 O(1), 이걸 N회 -> O(N)

## map
- O(NlogN)
- 동일한 N에 대해서 unordered_map이 10만이면, map은 100000 * log(100000) ~= 170만번

# sort
- O(NlogN)
